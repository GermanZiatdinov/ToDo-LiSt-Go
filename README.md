# ToDo List на Go

Учебный проект для закрепления первой части курса по Golang.

## О проекте

Консольное приложение «Список дел», которое работает с пользовательским вводом.  
Проект создан для отработки: структур, методов, мап, указателей, `defer`, работы с пакетами и сторонними библиотеками.

## Возможности

- **Добавление задач** — заголовок (одно слово) и текст (любое количество слов)
- **Просмотр всех задач** — полный список с датами создания
- **Отметка задачи как выполненной** — с запоминанием времени выполнения
- **Удаление задачи** — по заголовку
- **История событий** — все действия пользователя и ошибки сохраняются
- **Красивый вывод** — с использованием библиотеки `github.com/k0kubun/pp`

## Команды

| Команда | Описание |
| `help` | Показать список доступных команд |
| `add {заголовок} {текст}` | Добавить новую задачу |
| `list` | Показать все задачи |
| `del {заголовок}` | Удалить задачу по заголовку |
| `done {заголовок}` | Отметить задачу как выполненную |
| `events` | Показать список всех событий |
| `exit` | Завершить работу программы |

## Технологии

- **Go** — язык программирования
- **Структуры и методы** — для описания задач и списка
- **Мапы** — для хранения задач по заголовку
- **Указатели** — для изменения данных в методах
- **`time.Time`** — для хранения дат создания и выполнения
- **`github.com/k0kubun/pp`** — для красивого вывода
